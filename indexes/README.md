# 多维度索引

同一份 5301 条覆盖记录被切成四套索引：

- `by-subject/`：按九科拆分。
- `by-region/`：按 31 个省级地区拆分。
- `by-year/`：按 2008-2026 年拆分。
- `by-exam-system/`：按 `新高考`、`老高考`拆分。
- `catalog.csv`：完整总索引。
- `catalog.jsonl`：逐行 JSON，适合程序读取。
- `hierarchy.json`：按科目/地区/年份/高考模式嵌套。

每条记录都带有年份、科目、地区、高考模式、改革起始年、卷别性质、覆盖状态、源文件和规范化 Repo 路径。
