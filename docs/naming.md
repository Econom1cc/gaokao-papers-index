# 统一命名规范

## 目录

`papers/<年份>/<科目>/<地区或全国>/<卷型>/<文件>`

- 通用全国卷、全国甲/乙卷、新课标全国Ⅰ/Ⅱ/Ⅲ卷统一放在 `全国` 目录，不按省份复制。
- 省级卷放对应省份目录。
- 共享区域卷使用约定地区名，例如 `黑吉辽蒙`、`陕晋宁青`，并在 manifest 中映射到成员省份。
- 年份统一四位数字，科目统一使用九个标准名称。

## 文件

`YYYY_科目_地区或卷型_材料类型_版本.ext`

示例：

- `2025_数学_全国II卷_原卷.pdf`
- `2025_数学_全国II卷_解析.md`
- `2025_物理_四川_原卷.pdf`
- `2025_物理_四川_OCR与考点.md`

材料类型统一使用：`原卷`、`解析`、`答案`、`OCR与考点`、`答题卡`、`听力`。

## 英语科目例外

英语科目统一采用 `PDF + md + mp3` 三类文件：

- `YYYY_英语_地区或卷型_原卷.pdf`：原卷 PDF。
- `YYYY_英语_地区或卷型_OCR与考点.md`：OCR 文本、答案、考点和来源说明。
- `YYYY_英语_地区或卷型_听力.mp3`：英语听力音频。

可选文件：

- `YYYY_英语_地区或卷型_听力原文.md`
- `YYYY_英语_地区或卷型_答案解析.md`

如果该年英语卷没有独立听力音频，则仅保留 `PDF + md`，不创建空 MP3。
