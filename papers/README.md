# 全国高考试卷文件

本目录保存 2008-2026 年全国九科高考试卷及派生识别文本，覆盖 31 个省级地区，并统一映射全国卷、新高考卷和地方卷。

## 当前规模

- 唯一试卷：2,662 套
- 原卷 PDF：2,662 份
- OCR Markdown：2,503 份
- 英语听力 MP3：164 份
- 当前文件体积：约 4.45 GiB

部分长扫描卷的 OCR Markdown 仍在补全，但对应原卷 PDF 已保存在仓库中。实际状态以 [覆盖矩阵](../data/coverage_matrix.csv) 和各索引页面为准。

## 存储结构

```text
papers/<年份>/<科目>/<地区或全国>/<卷型>/<文件>
```

- 年份范围：2008-2026
- 科目：语文、数学、英语、物理、化学、生物、政治、历史、地理
- 地区：全国及 31 个省级地区
- 通用全国卷、全国甲/乙卷、新课标全国卷和新高考全国卷只在 `全国` 目录保存一份，省级覆盖关系见 [data/coverage_matrix.csv](../data/coverage_matrix.csv)
- 省级卷和区域共享卷使用对应地区目录

## 文件命名

`YYYY_科目_地区或卷型_材料类型.ext`

常用材料类型：

- `原卷`：试卷 PDF
- `OCR与考点`：OCR 正文及来源信息 Markdown
- `听力`：英语听力音频
- `解析`、`答案`、`答题卡`：有独立文件时使用

## 老高考综合科目

老高考理科综合中的物理、化学、生物按科目拆分为独立文件，但卷型名称保留“理综”：

- 四川老高考：`四川理综`
- 新课标全国卷：`新课标全国Ⅰ/Ⅱ/Ⅲ卷理综`
- 全国甲/乙卷：`全国甲卷理综`、`全国乙卷理综`

政治、历史、地理同理保留“文综”归属。这样既可快速按科目检索，也不会丢失原综合卷信息。

## 英语科目

英语通常使用 `PDF + md + mp3`：

- `YYYY_英语_地区或卷型_原卷.pdf`
- `YYYY_英语_地区或卷型_OCR与考点.md`
- `YYYY_英语_地区或卷型_听力.mp3`

没有独立听力音频的年份只保存 `PDF + md`，不创建空音频文件。
