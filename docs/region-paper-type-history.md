# 各地区高考使用试卷类型变迁

> 数据范围：2008-2026。本文仅说明各地区新老高考制度切换与卷型变化，缺失与覆盖统计请见 [九科缺失审计](missing-audit.md)。年度卷型来自仓库源文件观测，制度改革节点以各地官方方案为准。

## 全国制度背景

| 批次 | 新高考首次考试 | 地区 |
|---|---:|---|
| 第一批 | 2017 | 浙江、上海 |
| 第二批 | 2020 | 北京、天津、山东、海南 |
| 第三批 | 2021 | 河北、辽宁、江苏、福建、湖北、湖南、广东、重庆 |
| 第四批 | 2024 | 江西、甘肃、黑龙江、吉林、安徽、贵州、广西 |
| 第五批 | 2025 | 山西、河南、陕西、内蒙古、四川、云南、宁夏、青海 |
| 尚未实施 | 截至2026 | 新疆、西藏 |

说明：浙江、上海为首批试点，2017 年新高考并非全国新高考 I/II 卷；各地主科使用全国卷、选考自行命题的时间和范围可能不同。

## 使用说明

- 若要查询某地区全部原始记录，请使用 `indexes/by-region/*.csv`。
- 若要查询某科目在不同地区的变化，请使用 `indexes/by-subject/*.csv`。
- 若要按年份查看全部地区，请使用 `indexes/by-year/*.csv`。
- 新老高考模式由地区改革落地年计算，不简单等同于是否使用全国卷。
