# 四川 2016-2025 试卷文件

本目录收录四川地区十年语数外物化生试卷：

- 60 份原卷 PDF
- 60 份 OCR 与考点 Markdown
- 10 份英语听力 MP3
- 合计约 157 MB

## 存储结构

```text
papers/<年份>/<科目>/<地区或全国>/<卷型>/
```

## 老高考综合科目

2016-2024 年老高考物理、化学、生物统一标记为理综归属：

- 2016：四川理综
- 2017-2020：新课标全国Ⅲ卷理综
- 2021-2024：全国甲卷理综

虽然文件按物理、化学、生物拆分，但卷型名称与目录均明确保留“理综”信息。
