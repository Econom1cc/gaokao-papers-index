1.关于细胞的生命历程，下列叙述错误的是( )
A. 人的受精卵、早期胚胎细胞和神经元都处于细胞周期中
B.人的肝细胞中 RNA  聚合酶基因表达，胰岛素基因不表达
C.毛囊细胞合成黑色素的功能下降是老年人白发产生的直接原因
D. 蝌蚪变态发育过程中，尾的消失是通过细胞凋亡实现的
答案 A
解析
A 错误：细胞周期指连续分裂的细胞从一次分裂完成到下一次分裂完成。神经元高度分化、不再分裂，
无细胞周期；受精卵、早期胚胎细胞可连续分裂，有细胞周期。
B 正确：肝细胞需转录 RNA  聚合酶维持基础代谢；胰岛素基因仅胰岛 B  细胞特异性表达。
C 正确：老年人毛囊黑色素细胞衰老，酪氨酸酶活性下降，黑色素合成减少，直接导致白发。
D  正确：蝌蚪尾部消失是基因调控的细胞凋亡，属于程序性死亡。
2.大规模生产治疗性单克隆抗体时，常采用悬浮细胞表达系统。下列叙述错误的是( )
A.该类抗体在细胞中的翻译起始于游离在细胞质基质中的核糖体
B.该类抗体在细胞的内质网和高尔基体中修饰加工
C.悬浮细胞在培养过程中出现增殖能力下降的原因是接触抑制
D. 一种治疗性单克隆抗体一般只能与一种抗原结合
答案 C
解析
A  正确：单克隆抗体属于分泌蛋白，翻译起始于细胞质游离核糖体，后转移至内质网核糖体继续合成。
B正确：分泌蛋白在内质网折叠、糖基化，高尔基体进一步加工、分类包装。
C 错误：悬浮生长细胞无接触抑制(贴壁生长才存在接触抑制)；悬浮细胞增殖下降是营养消耗、代谢废
物积累、细胞衰老导致。
D 正确：单克隆抗体具有特异性，一种抗体只能特异性结合一种抗原。

7.将 物 种A  的启动子与物种 B 的生长激素基因编码序列重组，导入到鲤鱼受精卵，获得多条转基因鱼。
与对照组相比，转基因鱼生长速率加快。下列叙述错误的是( )
A.来源不同的启动子和基因编码序列可重新组合并表达
B.不同转基因鱼中重组生长激素基因的表达水平相同
C.外源基因整合到染色体 DNA  上是其在受体细胞中稳定遗传的关键
D.调控启动子活性可验证转基因鱼的生长速率与生长激素基因表达水平的关系
答案 B
解析
A 正确：基因工程原理为基因重组，不同物种启动子+编码序列可拼接，共用一套密码子，能正常表达。

C 正确：外源基因整合到染色体 DNA ，随染色体稳定复制分裂，才能稳定遗传；游离质粒易丢失。
D 正确：改造启动子(增强/减弱活性)，改变基因表达量，对比生长速率，验证二者关联。
8.关于过氧化氢酶的叙述，错误的是( )
A.过氧化氢酶可以降低 H₂O₂ 分解反应所需的活化能
B.若用过氧化氢酶探究温度对酶活性的影响，应设置不加酶的对照组
C.持 续 升 高H₂O₂浓度不一定加快过氧化氢酶的酶促反应速率
D.过氧化氢酶活性随 pH 降低而降低，随 pH 升高而升高
答案 D
解析
A 正确：酶作用机理是降低化学反应活化能。
B 正确：探究温度影响酶活性，需空白对照(不加酶，排除温度直接分解 H₂O₂ 干扰)。

D 错误：酶存在最适 pH 。低 于 最 适pH ，活 性 随pH 升高上升；高于最适 pH ，活 性 随pH 升高下降；过酸
过碱永久失活。并非单纯随 pH  升降单向变化。

10.马达加斯加有 6 种猴面包树，其中 Adansonia za(Az)的生态位最宽，且分布区与其他猴面包树物种
重叠。下列叙述正确的是 ( )
A.猴面包树中 Az  占据优势地位，种群数量最大
B.与 Az 存在较大生态位重叠的其他物种会被 Az 淘汰
C.猴面包树种间生态位分化不只是物种间相互作用的结果

解析
A 错误：生态位宽≠种群数量最大，生态位指资源利用、空间、时间等综合维度，与种群数量无必然关

D 错误：即使生态位不完全重叠，共用部分资源就存在竞争；竞争强度与重叠程度正相关，但零重叠也
可能共用资源产生竞争。

D.若监测到该地细辛和芒草数量明显降低时，应采取及时补种等保护措施
答案 ACD
解析
A 正确：虫卵、蛹、不能飞行的初羽化成虫活动能力弱，适用样方法。
B错误：灌木个体体积大、分布稀疏，相比草本细辛、芒草，应扩大样方面积，而非缩小。
C 正确：围栏 (人类保护干预)使围栏内外种群变化趋势不同，体现人类活动改变群落数量动态。
D 正确：细辛是虎凤蝶寄主植物，食物减少会导致蝶种群衰退，需补种保护。

### 第 8 页

16.某人颈脊髓损伤，失去行走能力。在安装脑脊接口套件后，该患者恢复了自主行走能力。该套件由三
个装置组成，如图所示：装置 1 安装在大脑皮层中央前回，负责采集信号；装置 2 穿戴于体外，负责对
装 置 1传来的信息解码并生成控制指令；装置 3 置于体内脊髓区，负
责将装置 2 的指令转换并传至控制下肢的脊髓运动中枢。下列叙述错
误的是 ( )
A.装 置1收到的信号与神经元的 Na⁺、K⁺跨膜运输有关
B.装 置2 和大脑皮层一样，具有随意支配下肢运动的能力
C.装 置3 刺激患者自主神经纤维释放电信号控制下肢肌肉收缩
D.该套件的应用证明大脑可不经反射弧直接支配下肢肌肉
答案 BCD
解析
A 正确：大脑皮层电信号为动作电位，依赖 Na⁺内流、K⁺外流跨膜运输。
B 错误：装置 2 仅解码信号、输出指令，无自主意识，不能像大脑皮层一样主动随意调控运动。
C 错误：支配肌肉的是躯体运动神经，不是自主神经(自主神经支配内脏、血管、腺体)；神经末梢释
放神经递质 (化学信号)，不是电信号。
D 错误：套件信号路径：大脑皮层→装置 1→ 装 置2→ 装 置3→脊髓运动中枢→传出神经→肌肉，完整反
射弧仍存在，大脑不能直接支配肌肉。
